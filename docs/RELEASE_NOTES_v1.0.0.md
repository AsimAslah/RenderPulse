# RenderPulse v1.0.0

First stable release candidate for secure 3D render status retrieval from Slack.

Highlights include a least-privilege `/model-status` command, signed-request verification, immediate webhook acknowledgement, authenticated Image-to-3D integration, controlled-channel authorization, accessible Block Kit messages, bounded retries, automated tests, and deployment documentation.

Do not publish this release as stable until the live sandbox app, deployed Pipedream endpoint, real backend status, acknowledgement latency, Slack response, CI checks, and redacted evidence have all been verified.
